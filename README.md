#  YouTube Music Redesign Extension v0.3.1

Redesign da interface do YouTube Music como uma extensão de navegador, focada em melhorar a experiência visual e usabilidade do player alem de deixar a interface mais moderna.

##  Sobre o projeto

Este projeto tem como objetivo recriar e melhorar elementos da interface do YouTube Music, trazendo:

* Melhor feedback visual
* Controles mais intuitivos
* Interface mais limpa, moderna, animada e reativa a som
* dar ao usuario opções de customização como ligar e desligar certas modificações
* rich presence com o discord

A extensão atua diretamente sobre o site do YouTube Music, modificando estilos e componentes da interface original.



##  Estado atual

### ✅ Funcional

* Slider de volume funcionando
* Barra de progresso funcional (controle de tempo da música)
* Interação com sliders operando como esperado
* player customizado
* pagina inicial
* menu lateral
* rich presence com discord(ainda com imagem placeholdere precisando de ajustes)

### ⚠️ Em ajustes

* Aparência visual da barra de progresso (cores/preenchimento)
* menu da sidebar com pequenos bugs visuais(não afetam na usabilidade)
* Ajustes visuais para melhor visibilidade em certas areas

## 🐞 Problemas conhecidos

* Elementos da interface original do YouTube Music podem sobrepor partes do redesign
* Pequenos bugs visuais
* Necessidade de ajustes finos em estilos (posição, cores, camadas)
* a interface da pagina inicial pode deixar de funcionar ao abrir o menu de musica e fechar

##  Como usar

1. Baixe ou clone este repositório:

   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. Abra o navegador (ex: Chrome)

3. Vá para:

   ```
   chrome://extensions/
   ```

4. Ative o **Modo do desenvolvedor**

5. Clique em **"Carregar sem compactação"**

6. Selecione a pasta do projeto

7. Acesse o YouTube Music e veja as mudanças aplicadas
